# HATTATSU GROUP — сайт

Статический лендинг (HTML/CSS/JS, без сборки). Дизайн-система: **Coinbase** (`awesome-design-md`), перенастроенная под бренд Hattatsu — тёмно-синий `#1E2470`, белый канвас, шрифт **Montserrat**, pill-кнопки, тёмные фуллскрин-блоки, ритм секций 96px. Геометрия hero — по образцу **Meta** (фото + двойной CTA). Соответствует макету `Макет сайта.pdf` и выбранному шаблону WeldWorks.

## Структура
```
index.html              — все секции
assets/css/styles.css    — токены + компоненты (правьте :root для палитры)
assets/js/main.js        — навигация, reveal-анимации, отложенная загрузка симулятора
```

## Запуск локально
```
python -m http.server 4173 --directory .
# открыть http://localhost:4173
```

## Бизнес-игра / симулятор
Встроен `https://mupamuc.github.io/dpo-play/` в секции `#simulator` (раздел Обучение → Геймификация).
Грузится по клику/прокрутке (не блокирует загрузку страницы). Движок — основа для корпоративных симуляторов под задачу клиента.

## Анимации (по ТЗ из переписки)
- Лёгкое «движение лого» (koi-float) — как на tarmacs.
- Подсветка/подъём блоков при наведении (`.card:hover`, `.member:hover`, `.doc:hover`).
- Появление секций при прокрутке (`.reveal`). Уважает `prefers-reduced-motion`.
